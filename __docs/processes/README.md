# Processes

How we work together on the things that need more than one person or more than one step to
get right. The daily flow for an individual developer is in the
[developer guide](../developer-guide/README.md); this folder covers the team-level agreements
that flow refers to.

- [Code review](code-review.md): what a reviewer checks, how to comment, who merges.
- [Database changes](database-changes.md): from an entity edit to an applied, reviewed migration.
- [Release](release.md): versioning, build order, deploy order, smoke checks, rollback.
- [Definition of done](definition-of-done.md): the checklist a change has to pass before the ticket closes.
- [Keycloak realm changes](keycloak-realm-changes.md): how to change roles, clients or users and get the change back into Git.
